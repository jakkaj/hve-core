#### CRITICAL

**QS-1**: `installation.md:27` — Extension identifier `microsoft.hve-core` is incorrect.
- **Issue**: The `code --install-extension microsoft.hve-core` command will fail. The actual publisher is `ise-hve-essentials` and the extension name is `hve-core`, making the correct identifier `ise-hve-essentials.hve-core`.
- **Impact**: Users following the CLI install path will get a "not found" error.
- **Fix**: Change line 27 to: `code --install-extension ise-hve-essentials.hve-core`
- **Patch**:
  ```diff
  -code --install-extension microsoft.hve-core
  +code --install-extension ise-hve-essentials.hve-core
  ```

#### MEDIUM

**QS-3**: `docusaurus.config.js` — GitHub org inconsistency.
- **Issue**: Config uses `jakkaj` as `organizationName` and in URLs, but the repo canonical path is `microsoft/hve-core`.
- **Impact**: Edit links and deployment URL point to a fork.
- **Fix**: This is a Phase 1 decision that Phase 2 inherited. Flag for Phase 4 integration review — no action needed in Phase 2.

**QS-7**: Multiple files — Mermaid hardcoded fill colors.
- **Issue**: 6 Mermaid diagrams use hardcoded fill colors (`#c8e6c9`, `#e8f4fd`, `#fff3e0`, etc.) that may be unreadable in dark theme.
- **Impact**: Diagrams may have poor contrast in dark mode.
- **Fix**: Test all diagrams in dark theme. Replace hardcoded colors with theme-safe alternatives or remove `style` directives.

**QS-6**: `intro.md:89` — Link/text mismatch.
- **Issue**: "Start with the Getting Started pages" links to `getting-started/value-delivery-loop` (a specific page, not the category).
- **Impact**: Minor user confusion.
- **Fix**: Reword to "Start with the [Value Delivery Loop](getting-started/value-delivery-loop) to understand the delivery model in depth, learn [how the architecture works](getting-started/how-it-works), and find the [right entry point](getting-started/quick-start) for your role."
